# Accesorios Ayala

Aplicación desarrollada en Flutter para la gestión de productos, clientes y generación de recibos.

## 🚀 Funcionalidades
- Registro de clientes
- Registro de productos
- Generación de recibos en PDF
- Vista previa de recibos
- Autenticación de usuarios

## 🛠️ Tecnologías utilizadas
- Flutter
- Dart
- SQLite
- Firebase

## 📱 Descripción
Esta aplicación permite administrar un negocio de accesorios, facilitando el control de productos y clientes, así como la generación de recibos digitales de forma rápida y sencilla.
